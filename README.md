# clockproc

Clock timestamps and proc durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/clockproc/

## Install / run

```bash
git clone https://github.com/theworker02/clockproc.git
cd clockproc
node src/cli.js
node --test
```
